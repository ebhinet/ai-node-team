## Decisions
_Significant choices made during execution — what was decided and why._

1. **Report styled with Option B palette** — Used Charcoal Umber dark cover page, Warm Ivory body backgrounds, Terracotta Rose for CTA buttons and accents, Burnished Gold for decorative rules. This gives Sara a preview of the brand in action.

2. **Three typeface strategy** — Inter for report UI/chrome text (layout descriptions, section labels, notes), Instrument Serif for copy headings rendered in preview blocks, DM Sans for copy body text rendered in preview blocks. This separates "report voice" from "website voice."

3. **Copy preview blocks** — All page copy is rendered inside styled preview containers using brand fonts and colors, so Sara reads the words as they would feel on the actual site. Layout descriptions are in Inter outside the preview blocks.

4. **Sitemap as visual diagram** — Built an SVG/CSS box-and-connector diagram rather than a bullet list. Shows hierarchy, sub-pages, and utility elements visually.

5. **Placeholder notes** — Called out all placeholder content (bios, testimonials, pricing, schedule, contact info) in gold-accented note blocks so Sara knows exactly what needs her real data.

6. **Print styles included** — Added @media print rules with page breaks after cover, sitemap, and before next steps.

7. **All four optional add-ons presented** — Blog/Journal, FAQ Page, Online Shop, Loyalty Program — each with "what it involves" and "why you might want it" in plain language.
