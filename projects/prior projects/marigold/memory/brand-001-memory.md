## Decisions
_Significant choices made during execution — what was decided and why._
_Captures rationale so a re-entering agent doesn't relitigate settled questions._

1. **Primary palette anchored on true marigold gold (#D4942A) and terracotta (#B5654A) — no sage-green as a primary.** Sara explicitly flagged generic sage-green/beige wellness palettes as an anti-pattern. Sage appears only as a sparse accent color, not a primary. The palette leads with warmth and color, not neutrality.

2. **Deep Umber (#3C2415) instead of black for text.** Keeps the entire palette warm. Pure black would introduce coldness that conflicts with the brand direction.

3. **DM Serif Display for headings.** Selected for its heft and rounded terminals — directly addresses Sara's requirement for grounded typography that is not thin or wispy. Considered Playfair Display but rejected it as too common in wellness branding and slightly more delicate.

4. **Source Sans 3 for body.** Humanist sans-serif with excellent screen readability. The warm proportions complement the serif heading face without competing. Chosen over more geometric options (Inter, Outfit) which would read cooler.

5. **Logo uses direct marigold flower reference, not abstract.** Sara named the studio after the flower — abstracting it away would lose the most immediate brand connection. The concept is a semi-geometric plan-view marigold bloom with layered petals, designed to work at multiple sizes.

6. **Imagery direction emphasizes detail shots and mid-practice angles.** Specifically avoids the "women in white rooms smiling at cameras" anti-pattern. Faces visible only in candid/practice contexts, never posed toward camera.

## Downstream Notes

**For brand-adversarial:**
- This direction intentionally avoids sage-green as a primary, using it only as a sparse accent. If the adversarial questions why green is nearly absent from an "earthy" palette, the rationale is that Sara's anti-pattern specifically calls out generic sage-green/beige combos.
- The logo concept is detailed enough for a designer to execute but is NOT an abstract/minimal mark. It is a recognizable marigold. This is a deliberate choice grounded in the studio name.

**For arch-001 (site architect) and downstream nodes:**
- The palette has a clear CTA color hierarchy: Marigold Gold for primary actions (Book a Class), Terracotta Clay for secondary actions. Deep Umber for text. This should map cleanly to button and link styling.
- Typography is a two-font system only (DM Serif Display + Source Sans 3). No third face is needed — Source Sans 3 Semibold handles subheadings and labels.
- Imagery direction favors close crops and detail shots over wide establishing shots. The architect should plan for image containers that work well with tightly cropped content, not panoramic/hero-landscape formats exclusively.
- Corporate wellness section can use slightly more structured imagery but must still lean warm — no cold/corporate stock photos even in the B2B context.
