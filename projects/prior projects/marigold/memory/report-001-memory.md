## Decisions
_Significant choices made during execution — what was decided and why._

- **No hex codes shown anywhere.** Colors are presented as large visual swatches with plain-language names and descriptions of where each color is used. Sara never sees a hex value.
- **Google Fonts loaded via standard link element.** All seven font families loaded: DM Serif Display, Source Sans 3, Instrument Serif, DM Sans, Caveat, Source Serif 4, Inter.
- **Inter used for report UI text.** The report's own chrome (labels, navigation, body copy) uses Inter for a clean, neutral reading experience. Each option's typography section renders actual text in the proposed fonts so Sara can see and feel the difference.
- **SVG logos built inline.** Option A: semi-geometric layered marigold with outer gold petals and inner terracotta petals. Option B: precise 9-petal geometric rosette with 40-degree rotation. Option C: hand-drawn marigold with varying stroke weights and subtle saffron wash fills. Each shown on light and dark backgrounds plus as a standalone icon.
- **Imagery direction presented as card grids.** Four cards per option: Mood & Lighting, What to Photograph, Color Treatment, and What to Avoid (distinguished with a warm accent border). Option C gets an additional Illustration Accents card.
- **Comparison section includes color bar swatches and a plain-language table.** The table compares Overall Feel, Colors, Headings, Logo Style, Photography, and Best For across all three options.
- **Tone is warm, friendly, and non-technical throughout.** Report speaks directly to Sara. No jargon, no CSS properties, no design terminology she would not naturally use.
- **Print styles included** with page breaks after cover and before each option section.
